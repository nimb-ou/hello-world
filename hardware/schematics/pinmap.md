# LORE Square: Pin Map / Netlist Table (reference, rev 0.9)

This is the companion to the `sheet01`–`sheet06` schematic sheets in this folder (generated by `gen_schematics.py`).

How to read it:

- **SoC ball names are indicative.** MediaTek's MT8391 ball map is under NDA, so final assignments come from the Genio 720 reference design.
- **Module pins** follow public datasheets: Quectel EG25-G / LC29H hardware design guides, Bosch BHI360 / BMM350 / BMP390, TI BQ25620 / TAS2563 / DRV2605L, Infineon OC1230, NXP SE050, PixArt PAT9125. Re-verify them at capture.
- **Voltage domains:**
  - VIO18 = 1.8 V AP I/O.
  - 1V8_SNS = always-on 1.8 V sensor domain.
  - VBAT_LTE = 3.8 V.
